This is a learning project used to practice basic web development in VS Code.

The demo currently consists of three files:

1. index.html — the page structure (square, buttons, label)
2. style.css — the visual styling (dark background, square appearance, button styling)
3. script.js — the interactive behavior (grow, rotate, and reset logic)
